# EventHorizon | Modern Event Management Website

A visually stunning, fully responsive, and interactive Event Management Website built with modern web technologies. It features real-time search, filtering, sorting, form validation, Local Storage persistence, and a polished dark/light mode UI.

## 🌟 Features

- **Modern UI/UX:** Clean design with smooth animations, hover effects, and a professional color palette.
- **Fully Responsive:** Optimized for mobile phones, tablets, laptops, and desktops.
- **Event Discovery:** Real-time search, category filters, and sorting by date or popularity.
- **Interactive Modals:** Detailed event views and a registration modal without page reloads.
- **Robust Registration System:** Client-side validation, duplicate prevention, Local Storage persistence.
- **Bonus Features:** Dark/Light Mode, Live Countdown Timer, Toast Notifications, Back-to-Top Button, Empty States.

## 🛠️ Technologies Used

- HTML5, Tailwind CSS (CDN), Vanilla JavaScript (ES6+), Font Awesome 6, Google Fonts (Inter)
